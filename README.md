## 🛠 Архитектура и детекция 11 типов ошибок

Инструмент `locqa` реализует детерминированный статический анализ без галлюцинаций:

1. **`untranslated`** — выявление пропущенных ключей (восстановлено 12 ключей).
2. **`same_as_source`** — отлов непереведенных русских строк с белым списком брендов, никнеймов и чисел.
3. **`placeholder_mismatch`** — проверка соответствия аргументов `{name}`, `{count}` и параметров `%s1/%s2`.
4. **`plural_mismatch`** — рекурсивный валидатор ICU plural/select-форм.
5. **`glossary_violation`** — контроль терминологии (например: «семья» ➔ «отбасы», «донат» ➔ «donat»).
6. **`length_overflow`** — эвристический контроль длины кнопок и вкладок UI (удаление паразитных хвостов).
7. **`machine_translation_suspect`** — поиск кальки и русских конструкций («иметь место», «круглосуточно»).
8. **`inconsistent_term`** — унификация переводов одних и тех же сущностей по всему интерфейсу.
9. **`suffix_harmony`** — выявление жестких аффиксов после плейсхолдеров (`{name}-ға`) и их грамматическая перестройка.
10. **`orthography`** — устранение опечаток и замена русских букв на специфические казахские (ә, ғ, қ, ң, ө, ұ, ү, һ, і).
11. **`wrong_language`** — детектор чужого языка (очистка от случайных узбекских строк).

## 🚀 Установка и быстрый старт

Утилита не требует внешних платных API и работает автономно на Python 3.10+:

```bash
# Переход в директорию с CLI
cd locqa_github_ready

# Установка зависимостей
pip install -e .

# Запуск полного аудита
locqa check \
  --source intl_ru.arb \
  --target intl_kk.arb \
  --glossary glossary.csv \
  --out report.json
